# testovinterior
Портфолио-сайт со всякими приколюхами для себя и будущих клиентов

## v2 — тестовая версия «Свет · Стекло · Пространство»

Новый сайт лежит в папке [`v2/`](v2/) и никак не трогает текущий, который остаётся в корне.

- **Адрес после публикации:** `https://valentintestov.github.io/testovinterior/v2/`
- **Правила оформления:** [`v2/DESIGN.md`](v2/DESIGN.md) — шрифты, цвета, стекло, 3D-сцена, звук.
- **Сборки нет:** обычные HTML, CSS и JS. three.js лежит в `v2/assets/vendor/`, шрифты — в `v2/assets/fonts/`.
- Папка самодостаточна: свои стили, скрипты, шрифты, обложки проектов и og-картинки.

Что дальше можно сделать с папкой:

- **Вынести в отдельный репозиторий** — скопировать содержимое `v2/` в его корень, включить GitHub Pages
  и заменить в тегах `og:url` и `og:image` адрес `…/testovinterior/v2/` на новый.
- **Сделать основным сайтом** — перенести содержимое `v2/` в корень вместо старых страниц
  и убрать `v2/` из адресов в `og:url` и `og:image`. Имена страниц те же (`ruletka.html`, `palitra.html`, …),
  так что старые ссылки и закладки продолжат работать.
